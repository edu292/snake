# 🐍 Jogo da Cobrinha com Pygame
Um clássico Snake game recriado em Python com Pygame, apresentando sprites personalizados, movimentação fluida e lógica modular. Controle a cobra, coma as maçãs e tente bater seu próprio recorde!

---

## 🎮 Sobre o Projeto
Este projeto implementa o famoso jogo da cobrinha, com um visual moderno usando sprites e uma grade colorida que dá mais vida ao tabuleiro. O jogo possui uma estrutura bem organizada em classes (Grid, Snake, Game, etc), facilitando manutenção e possíveis expansões futuras.

- 🧠 Funcionalidades
- ✅ Movimento fluido e responsivo
- 🍎 Geração aleatória de comida
- 🧠 Lógica modular (grade, cobra, jogo, comida)
- 🎨 Sprites personalizados para a cobra e a comida
- 🔁 Reinício automático ao colidir com a parede ou consigo mesma

---

## 🕹️ Controles

| Tecla |	Ação |
|------|-------|
| W / ↑	| Mover para cima       |
| A / ←	| Mover para a esquerda |
| S / ↓	| Mover para baixo      |
| D / →	| Mover para a direita  |
| ESC	  | Sair do jogo          |

---

## ▶️ Como Jogar
Clone o repositório:

```
git clone https://github.com/edu292/snake
```
Baixe as dependências

```
pip install requirements.txt
```
Inicie o jogo

```
python main.py
```
